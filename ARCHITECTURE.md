## Auth-контракт

JWT в httpOnly cookies.

| Метод | Путь | Вход | Действие |
|---|---|---|---|
| POST | `/api/auth/register` | email, password, displayName | Создаёт пользователя, ставит cookies, возвращает user |
| POST | `/api/auth/login` | email, password | Проверяет пользователя, ставит cookies, возвращает user |
| POST | `/api/auth/refresh` | refresh cookie | Отзывает старую refresh-сессию, создаёт новую пару токенов, возвращает user |
| POST | `/api/auth/logout` | — | Отзывает refresh-сессию, очищает cookies |
| GET | `/api/auth/me` | access JWT | Проверяет access JWT, возвращает текущего пользователя |

## Обновление 6 августа 2026 — объём и пользовательский сценарий

Дополнение к решениям выше по итогам обсуждений в чате команды, без части участников.

### Решение по объёму

Обсуждали урезание MVP. Решили **не резать** — весь функционал ниже входит в план как есть.

### Полный пользовательский сценарий

1. Регистрация/вход
2. Создание питомца (имя + выбор персонажа) — отдельный экран после первой авторизации
3. Короткое обучение (зачем питомец, как получать опыт, какие награды, бонусы в Авито)
4. Главный экран: питомец, уровень, опыт, монеты, настроение, сытость, энергия, кнопки
   действий, доступные задания, ежедневная награда

### Характеристики питомца

| Характеристика | Как меняется |
|---|---|
| Уровень | Растёт от опыта, открывает аксессуары |
| Опыт | Начисляется за вход/игры/уход/задания |
| Монеты | За игры/задания/достижения; тратятся на еду и аксессуары |
| Сытость | Падает со временем, восстанавливается едой (3 вида) |
| Настроение | Растёт от игр и заходов, падает от голода и отсутствия |
| Энергия | Максимум 100, ~20 за игру, восстанавливается со временем |

### Мини-игра

Питомец-курьер Авито ловит товары/коробки, избегает бомб/брака. Ограничена по времени,
очки конвертируются в опыт и монеты, есть множитель за серию.

**⚠️ Открытый вопрос (не решено): исполнитель мини-игры не определён.** У @yzhenevstavlyaet
уже два фронта (auth + pet), поднимался вопрос не перегружать его третьим. @yzhenevstavlyaet
предложил разделить работу над игрой на всех троих бэкендеров. Финальное решение — на
сегодняшнем созвоне. Не закреплять мини-игру ни за кем заранее.

### Задания

Три типа: ежедневные, общие/долгосрочные и вне игры (связаны с реальными действиями в
Авито — открыть приложение, посмотреть объявление, разместить объявление).

**Решение по подходу:** сейчас реализуются только заглушки для заданий вне игры (например,
кнопка «отметить выполненным» без реальной интеграции) — это не приоритет сейчас. Реальная
интеграция с Авито планируется позже через Kafka UI (предложил @yzhenevstavlyaet) и/или
вебхуки (предложил @NBx03) — это план на будущее, сейчас не реализуется.

### Лидерборд и ежедневная сводка

Зона @sonofche.

- **Лидерборд:** две таблицы — по уровню и по результату мини-игры.
- **Ежедневная сводка:** при первом входе за день — время отсутствия, изменения
  сытости/настроения, восстановленная энергия, опыт/монеты за вчера, рекорд мини-игры,
  награды.
